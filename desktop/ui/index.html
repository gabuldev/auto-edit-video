            Como conectar (uma vez só, uns 5 minutos)
            
        O YouTube só aceita vídeos enviados por um app registrado no Google Cloud. Você cria o seu (é grátis), baixa um arquivo de credencial e escolhe ele aqui.
        
            
          
              
        1. Crie um projeto no Google Cloud, com a conta Google do seu canal. Abrir o Google Cloud
          2. 
              
        2. Ative as duas APIs do YouTube: a Data API v3 (envio) e a Analytics API (retenção). Em cada uma, clique em Ativar. YouTube Data API v3 · YouTube Analytics API
          3. 
              
        3. Configure o acesso: no Google Auth Platform, clique em Primeiros passos, dê um nome ao app e escolha Externo. Depois, em Público-alvo, adicione o seu e-mail como usuário de teste. Abrir o Google Auth Platform
          4. 
              
        4. Crie a credencial: em Clientes → Criar cliente, escolha o tipo App para computador e baixe o JSON. Criar cliente
          5. 
              
        5. Escolha o JSON aqui. 
          6. 
              
        6. Conecte: clique em Conectar YouTube. O navegador abre pra você escolher o canal e autorizar. Se o Google avisar que o app não foi verificado, é o seu próprio app: clique em Avançado e continue.
          7. 
            
        
            
        Em modo de teste, o Google desconecta a cada 7 dias. Pra não expirar, clique em Publicar app em Público-alvo (pra uso próprio não precisa de verificação). E enquanto o projeto não passa pela auditoria do YouTube, os vídeos enviados ficam privados: é só liberar no Studio.
